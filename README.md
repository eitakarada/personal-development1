# CieloEmo（シエロエモ）

「心を動かした言葉を、夜空に残そう。」

本や映画、ドラマ、漫画、音楽、友人との会話などで出会った「心に残る言葉」を保存し、自分だけの星空として記録するサービス。

## 主な機能

- 📝 **言葉の登録**：感情を選んで夜空に星として保存
- 🌟 **感情カラー**：8つの感情ごとに異なる色と輝きで表示
- 🌌 **振り返り機能**：過去の星を呼び戻して、今の自分からメモを残せる
- 👥 **フレンド機能**：友達の公開した星を自分の夜空に追加
- 🔍 **検索・統計**：感情別の分布や言葉の検索
- ✨ **五つの星**：自分を表す大切な星を5つ選んでランキング表示
- 💬 **コメント**：フレンドの星にコメントを残せる
- 📅 **期間表示**：星空を全期間・年・月・週で絞り込める

## 使い方

1. 「新規登録」からユーザー名、メールアドレス、パスワードを登録する
2. ログインして、ホーム画面の `+` ボタンから心に残った言葉を登録する
3. 言葉の作者、出典、心に残った理由、感情を入力する
4. 星空の星をクリックすると、登録内容の確認、編集、削除、公開設定の変更ができる
5. 「振り返り」から過去の星を選び、現在の自分のメモを追加する
6. 「五つの星」で、自分を表す星を最大5つ選ぶ
7. 「フレンド」でメールアドレスからユーザーを検索し、申請・承認する

公開設定を無効にした星は、フレンドの夜空には表示されません。フレンドから受け取った星は、自分の夜空にコピーして保存できます。

## 起動方法

Docker で PHP 環境を起動します。

```bash
docker compose up --build
```

ブラウザで次を開きます。

```text
http://localhost:8888/
```

`docker-compose.yml` を使わずに起動する場合は、次のコマンドでも実行できます。

```bash
docker build -t cieloemo .
docker run --rm -p 8888:8000 cieloemo
```

## 無料で公開する（Render）

このリポジトリには Render 用の `render.yaml` を用意しています。

1. GitHub にこのリポジトリを push する
2. Render に GitHub アカウントでログインする
3. `New` → `Blueprint` を選び、このリポジトリを接続する
4. `cieloemo` サービスを作成する

Renderの環境変数に次を設定すると、アプリはSQLiteではなくSupabase PostgreSQLを使用します。

```text
DATABASE_URL=SupabaseのPostgreSQL接続文字列
```

無料プランでは一定時間アクセスがないとサービスがスリープし、最初のアクセスに時間がかかります。Renderの無料Web Service自体には永続ディスクがないため、本番では外部データベースを使用してください。

## データ保存

- ローカル: SQLite（`project/data/auth.sqlite`）
- 公開環境: `DATABASE_URL` が設定されている場合はSupabase PostgreSQL
- パスワード: `password_hash` でハッシュ化して保存

ローカルSQLiteからSupabaseへ既存データを移行する場合は、先にSupabaseでテーブルを作成し、次のスクリプトを実行します。

```powershell
Set-Location "C:\Users\<ユーザー名>\personal-development1"
.\tools\migrate.ps1
```

スクリプトはパスワードを画面に表示せず、入力した接続情報をファイルへ保存しません。データベースのパスワードや接続文字列はGitHubへcommitしないでください。

## 画面構成

- トップ（`/`）：新規登録・ログイン
- ホーム（`/home/`）：星空メイン画面
- ログイン（`/auth/login.html`）
- 新規登録（`/auth/registar.html`）

## ディレクトリ構成

```text

	home/      星空画面

supabase/    PostgreSQL用スキーマ
```

## 無料プランの注意

- Renderはアクセスがないとスリープする
- 無料サービスは大量アクセスや大容量データには向かない
- Supabaseにも容量、通信量、接続数などの上限がある
- 大切な記録は定期的にバックアップする
- 接続文字列やデータベースパスワードは公開しない
